# Mary Grace & J-Rex Hero Wedding Invitation Website

A digital flipbook wedding invitation for Mary Grace & J-Rex Hero (December 18, 2026).

## Files Included:
- `index.html` — The main flipbook application page (including the grid dress code section).
- `styles.css` — Responsive design, page animations, swatches, and attire grid styling.
- `script.js` — Flipbook logic, dynamic content populator, lightbox photo gallery, and RSVP handler.
- `data.json` — Event details, wedding party, schedule, and venue info.
- `photos.json` — Background images and prenup photo gallery paths.

## Setup Instructions:
1. Extract all files to your web server or repository (e.g., GitHub Pages, Netlify, Vercel).
2. Ensure your photo assets are placed in the `photos/` directory as mapped in `photos.json`.
3. Open `index.html` in a web browser to preview.
